# 記録手帳の解析状況

現在のGekiOperationCatalogに残る、前作業のエミュレーター実測を整理した。今回新たにAzaharを実行した結果ではなく、実機の固定操作としての再検証も未完了。

| 操作 | 既存データの消費 | 条件 |
|---|---:|---|
| 記録手帳をカテゴリ選択まで開く | 0 | モデルを表示しない |
| カテゴリを3項目移動 | 0 | 選択だけ |
| アンテナ一覧の表示・項目移動 | 0 | 記録された経路に限る |
| アイテム・そうびの3項目移動 | 0 | 記録された経路に限る |
| インテリア一覧を開いて戻る | 0 | 所持1項目の試行 |
| いちごおばけを表示してすぐ戻る | 10 | 同じセーブ、11試行との既存記録 |
| いちごおばけ→タケノこぞう→戻る | 20 | 1試行 |
| モンスター3項目移動して戻る | 40 | 2試行 |
| モンスター1・2・3往復して戻る | 30・50・70 | 各1試行 |
| モンスターを長く表示して戻る | 15・20 | 変動。固定手順に使用しない |

モデル表示の操作区間には時間経過による消費が混ざる。既存試行から未検証のモンスターや任意回数へ外挿しない。実機で手帳経路を手順に追加するには、島のメニューの開く前→いちごおばけを表示してすぐ戻った後→同じ経路をもう一度行った後、の3記録で各区間を照合する。ゲームの起動シードは不要で、同じ起動の内部状態差を使う。
