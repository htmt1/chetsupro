# けつぷろ / chetsupro

電波人間のRPG FREE! 1.17.0のシード検索・キャッチ個体検索・出生ルート作成ツール。

## 保存データ

シード・親候補・個体番号は利用者それぞれのブラウザ内に保存します。利用者間の自動共有・クラウド同期はありません。別端末への移動にはファイル保存・読み込みを使用してください。

## 公開・更新

公開ファイルは `site.zip` です。`.github/workflows/pages.yml` が展開し、GitHub Pagesに配信します。GitHubのSettings → Pages → SourceはGitHub Actionsを選びます。更新時は `site.zip` を差し替えてmainにコミットします。

## 計算結果

研究モデルによる予測です。補充枠・所有個体との重複再抽選など一部未対応です。実際のゲーム内個体と照合して使ってください。
